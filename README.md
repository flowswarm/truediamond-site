# True Diamond Life Care Group — Website

Multi-page static site (plain HTML/CSS/JS, no frameworks). Content comes from the
"Website Breakdown" PDF; layout mirrors the reference site's structure
(top bar → sticky nav with dropdowns → hero + inline form → feature trio → about →
services → FAQ accordion → CTA band → articles → affiliation strip → commitment cards →
contact → footer with map + disclaimer). All images are blank placeholders.

## Run it on localhost

Option A — Python (already on most machines):

    cd site
    python -m http.server 8080

Then open **http://localhost:8080** in your browser.

Option B — Node:

    npx serve site
    # or: npx http-server site -p 8080

Option C — VS Code: install the "Live Server" extension, right-click `site/index.html`
→ "Open with Live Server".

(Opening `index.html` directly from the file system also works, since every link is
relative, but a local server is closer to how it will behave when hosted.)

## Editing

- **Content / header / footer:** edit `build.py`, then run `python3 build.py` to regenerate
  every page at once. (You can also edit the HTML files directly if you prefer — just
  remember the header and footer are repeated on every page.)
- **Colors, fonts, spacing:** `site/assets/style.css` (palette variables at the top).
- **Menus, FAQ accordion, mobile nav, form behavior:** `site/assets/main.js`.

## Images

- `site/assets/images/` — logo, favicon, founder photo, affiliation logos (CGC, NGA, CGE).
- `site/assets/images/illus/` — original SVG illustrations in the brand palette, one per
  service page, article card, the About mission block, Who We Serve, Contact, the footer
  map, and the six "What You Can Expect" value icons. They are generated by
  `make_illustrations.py`; edit that file and re-run it to tweak any of them, or simply
  drop a photo/JPG in their place by changing the `src` in `build.py` (search `illus(`).
- The footer map can be swapped for a live Google Maps embed `<iframe>` later.

## Forms (email delivery)

All forms (consultation, contact, sidebar "Stay in Touch") send to **owner@truediamondlcg.com**
through FormSubmit (https://formsubmit.co) — a free relay for static sites, no account needed.

One-time activation: the FIRST time a form is submitted, FormSubmit emails
owner@truediamondlcg.com an "Activate form" link. Click it once and every submission after
that is delivered as a tidy table (name, email, phone, message, which page it came from).
Replies go straight to the visitor's email address.

Notes:
- Forms submit in the background and show a thank-you message on the page. Submissions only
  work when the site is served over http(s) (localhost server or live hosting), not when the
  HTML is opened directly as a file:// path.
- To change the destination address, edit `email` in `BIZ` at the top of `build.py` and re-run it.
- To re-enable FormSubmit's captcha, change `_captcha` to `true` in `form_hidden()` (then the
  visitor is sent to a FormSubmit page to confirm instead of staying on the site).

## Fonts

Headings use Playfair Display and body text uses Lato, loaded from Google Fonts.
If you want the site fully offline, download those fonts into `assets/fonts/` and
replace the `<link>` tags in `build.py`.
